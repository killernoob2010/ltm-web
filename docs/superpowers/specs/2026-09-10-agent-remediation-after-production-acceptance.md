## 3. 修复设计

### 3.1 权限与公开请求的服务端硬边界（先做）

1. 在同一个服务端注册表登记模块、工具、基础必需资源、字段额外资源、接入状态及只读属性；模型目录和调用鉴权均从该表生成。六模块分类不替代原有子资源权限。
2. 先规范化实际返回字段，再算权限。fields 省略时采用当前用户可读的安全默认字段；显式请求无权字段返回明确拒绝，不静默返回。SQL选择、预览、完整行、快照、图表与证据采用同一字段集合。
3. 所有源结果保存实际字段和必需权限；派生结果保存全部父引用及资源并集。敏感字段请求必须保存 data 权限依赖，即使结果为空或异常也不旁路暴露原始行。
4. 检查现存快照；来源元数据缺失时拒绝复用或仅在可证明字段/权限的严格白名单下兼容。默认引导重查，不全库删除，不把旧默认 display 当充分授权。
5. 后台禁止规则先于管理员通常放行；禁止资源包括用户、权限、日志、配置、质量详情与评估数据。内部鉴权读取最少身份信息可以保留，但不返回给模型。
6. 公开工具执行层每次校验当前运行、用户、执行标识、计划版本及 research_requirement。缺计划、读取失败、任务结束、其他用户计划全部拒绝，search_public/read_public 直接调用也一样。
7. 公开搜索词只含公开主题；私有上下文过滤同时覆盖本轮和仍被引用的历史结果/用户内容。禁用用户、撤权、跨会话结果及伪造游标分别测试。

### 3.2 子问题计划、否定语义与多轮上下文

增加受限结构化计划，最低字段：subquestion_id、当前目标、source_kind、module、period、required_output、research_requirement（required/optional/forbidden/conflict）、必要历史引用。资源集合只由注册表推导。

普通明确的单一问题可走确定性快路径；组合、同义/否定及追问走一次结构化语义规划，计入当前总预算。无论哪条路径，都必须生成相同契约。规划不能授予权限或取消用户禁止联网要求。

“不要联网，只查库存”“不需要实时估值或联网”“无需网络查询”都应得到 forbidden；只有不同子句真正同时要求与禁止同一外部操作才澄清。过去允许联网不延续为本轮许可。

只选取当前问题需要的历史指代与已重新鉴权的结果目录。独立新问题不重答旧问题；“将刚才表格改为图”复用同一仍有效结果；“更新”才查新快照。历史普通文字中引用了已撤权结果的内容不得重新送入模型。前端补新建对话/切换对话的提交屏障及异步序号校验；当前已有 state.loading 守卫，不把测试操作过快直接认定为前端串会话根因。

### 3.3 正确拒答与按子问题保留成果

服务端维护每个子问题的结果：completed、partial、not_connected、forbidden、unavailable、clarification_required、budget_blocked；配套来源引用、完成字段和原因代码。

- 全部为禁止/未接入时，服务端生成确定性政策说明；这类说明依据授权判定，不要求模型编造业务result_ref。
- 订单融资：“当前尚未接入，无法查询内部融资数据。”不能只建议调整用户权限就能解决。
- 后台：“后台管理信息不通过业务Agent提供，管理员也受此限制。”
- 混合请求逐项处理，受限子问题不影响可读子问题；整体覆盖按要求计算。界面分别显示“已完成/部分完成/未接入/禁止访问/服务故障”，不把拒答叫“数据完整”。
- 格式或证据修复仍最多一次；服务端保留已验证表格、来源及独立段落。单段无效仅删除该段及其依赖；不能保留依赖失败数据的结论。
- 预算、超时和工具异常统一经过同一协议的安全降级出口，保留本次已验证结果；修复和降级交付前重新授权。

### 3.4 多年查询、年度计算与大结果

先描述数据真实覆盖、频率、粒度和来源版本，再制定查询。指定2022–2026不代表数据源有五年记录；明确显示请求期间、实际期间、缺失年份。不得反复换年份尝试制造不存在的数据。

新增服务端 query_group：绑定规范化查询、来源版本/一致性令牌、用户/会话、资源集合、稳定排序和完成状态。单批继续沿用现有行数/字节上限；next_cursor 由服务端生成并签名，绑定筛选及来源版本，按日期+稳定唯一键续查，支持同日超批量。

有版本的数据固定源包；没有现成版本的数据用一致快照或变更检测，发现变化则停止并重新开始，不混算。最终全量汇总必须证明无重无漏。超单任务预算时提供继续读取入口，下一任务承接同一query_group并重新鉴权。查询进度不让模型逐页搬运明细。

服务端增加按年派生维度及登记聚合方法。库存属于时点存量：先按同一观察日汇总不重复叶子数据，再按明确方法计算年度期末/观察期均值/同周对比，不能跨日期相加。年度比较无明确方法时采用已登记口径并向用户说明；没有已登记口径则澄清。均值应区分观察点平均和时间加权平均，后者未经确认不默认实现。流量按时间覆盖去重累计；价格不加总；不完整年度不得冒充全年。

图表与表格来自同一结果。连续图保持真实日期，季节图保持年份与周定义，闰周缺失保留。超总点数/曲线/字节则分面分页或完整表格降级，解释覆盖，不静默抽样。表格预览截断与底层完整快照分开标识。

### 3.5 工具错误与持仓查询

先补错误分类，再复现 #30：保存 task/subquestion/tool、phase、整数秒耗时、安全错误类别、可否重试及关联诊断编号；仅在受控服务端日志保存必要细节，模型与业务页面不获得凭据或异常原文。

MCP结构化错误至少区分：参数不合法、无权限、数据库超时、来源不可用、行情不可用、快照保存失败、任务预算终止。客户端保留分类，不再把全部错误压成 RuntimeError。检查数据库阶段执行计划与语句超时、事实查询结果、序列化及保存阶段；当前证据不能直接归因CPU或行情。

给持仓工具增加明确的 valuation_mode/required_metrics 参数。只查数量时不调用行情；查询浮盈亏时仍严格用最新成交价并返回时点。行情失败保留数量；数据库事实失败不能用旧数量冒充最新。默认行为保持兼容，计划根据用户实际字段决定是否估值。禁止通过延长所有超时、替换结算价或无界重试掩盖失败。

目录发现和业务调用分别计数并展示，但仍受全任务有界预算。缓存同一任务内不变的目录/数据描述；相同查询复用结果，避免反复describe/query。预算不足优先交付已完成子问题并说明续查条件。

### 3.6 公开研究真实接入

复用当前搜索供应商与正文阅读链路；先核对既有凭据配置存在性、费用授权及剩余额度，不输出密钥。缺凭据作为配置受阻，不再标成意图识别失败。新增非敏感readiness字段：未配置、鉴权失败、不可达、可用；只有实际连接检查后才能判可用。

真实验收必须取得搜索结果、读取至少一个有效正文、保存来源URL/发布日期或未知日期、绑定对应结论，并人工回读来源。搜索空结果、403、超时、只有摘要、正文不可读分别记录。外部失败时内部成果保留，公开事实必须有对应证据，搜索0次不得称联网成功。

### 3.7 Evaluation执行、持久化与发布判断

定义检查、合成执行、真实模型运行、规则评分和人工复核分开记录。真实调用并不自动等于通过；读取运行日志也不等于已经评估。

建议新增三张隔离评估附表：evaluation_batches（版本、环境、数据集、预算、执行范围）、evaluation_case_results（case/run关联、执行来源、事实快照、断言与证据、结果）、evaluation_reviews（评分修订/人工审计）。命名按项目约定。这是拟议数据库变更，实施前先提交迁移、备份、恢复验证及最小授权影响；不能因此前宣称“不加表”而用操作日志承载整套不可查询批次。

现有运行表优先用事件记录补 app/model/prompt/policy版本、production/acceptance/eval流量类别、子问题覆盖和安全用量。旧记录字段未知保留unknown，不补造历史版本。

live执行器经当前任务/Harness/MCP链路，以显式身份、用例ID、目标环境和预算执行；不暴露HTTP一键任意执行入口。oracle只进评分器，不进入被测Agent提示。支持中断恢复、运行幂等、预算耗尽标blocked，避免重复收费。

确定性评分覆盖：权限/禁止工具、字段泄露、联网禁止、必须公开来源、数值和单位、源时间、分页完整性、引用、子问题覆盖与预算退出。不能判解释正确的记needs_review。人工复核保留评审者类型（human/agent/rule）及修订记录，自动化代理评语不得记成人工结论。

现有 #25–#30 可关联为“人工操作的真实运行、代理观察、当前版本证据”，不能补造当时没有的源快照或固定oracle。失败例进入脱敏回归候选，同时保留独立holdout。

版本比较绑定相同数据、权限、评分版本及用例；实时数据变化标不可直接比较。越权、后台泄露、伪造证据、私有外发硬失败，不能平均抵消。必需项受阻/未执行时阻止“整体通过”，允许如实发布受限能力。

### 3.8 运行质量后台

完成四项视图：运行概况、质量与反馈、调用明细、版本验收。展示任务、需求覆盖、质量判定三种不同状态。

查询改SQL筛选+COUNT+分页与分组聚合，消除全量fetchall及逐行模块查询。列表、卡片、导出采用同一筛选对象，白名单验证state/module/channel/version。模块归属来自子问题计划及工具注册表，公开研究作为能力类别，不虚报信息预警模块接入。

默认近7天，可选30天及自定义，按Asia/Shanghai计算日界线后转换存储时区；页面明确北京时间，统一整秒。测试23:59:59/00:00:00。无匹配任务时反馈统计为0，不读取全量历史反馈。无费用依据显示未知。默认正式使用统计排除acceptance/eval流量，旧未分类记录标未知，不能假定普通生产调用。

详情增加独立审阅权限及来源权限策略：默认脱敏摘要；明确授权管理员才能打开对应正文/证据。所有后台路径继续对业务Agent禁止。前端显示安全错误类别、工具状态、耗时和证据引用；提供真实批次和逐例结果，移除固定not_recorded逻辑；没有数据时仍如实显示未记录。

# WH6 成交与持仓采集器 Windows x64 便携程序

这里保留 Windows 构建说明，不放入二进制、账户令牌或任何 Supabase 密钥。最终交付物是版本化的单文件 `WH6成交采集器.exe`；本机 Mac 环境不能生成 Windows 二进制，因此必须在 Windows x64 CI 或 Windows 11 构建环境生成并验收。

## 一键构建

在 Windows x64 构建环境把项目目录复制完整，然后双击项目根目录的：

```text
生成WH6安装包.cmd
```

也可以直接运行：

```text
collector\installer\build_windows.cmd
```

脚本会自动完成以下动作：

1. 查找 Python 3.11 x64；如果构建环境安装了 `winget`，缺少时可选择自动安装；
2. 创建临时构建虚拟环境并安装锁定版本的 PyInstaller；
3. 清理旧的构建目录，生成不依赖目标电脑 Python 的单文件 `WH6成交采集器.exe`；
4. 将程序、SHA-256 校验文件和构建说明写入 `collector\releases\<版本>\`；
5. 扫描构建来源，拒绝出现数据库密码、`service_role` 或 `DATABASE_URL`。

构建环境需要 Python 和联网安装依赖；目标 Windows 电脑不需要安装 Python、PowerShell、PyInstaller 或安装器，也不要求管理员权限。构建过程不会把令牌、账户号或数据库凭据写入程序。运行时配置、队列、备份和设备令牌位于 `%LOCALAPPDATA%\WH6成交采集器`，不写入 WH6 `Record` 目录。

## 运行与验收边界

- 目标电脑直接双击版本化 EXE；首次运行只选择 WH6 `Record` 目录、确认脱敏账户并输入 Web 页面生成的一次性连接码。
- 连接码自动决定绑定到测试版或正式版；程序只显示绑定结果，不提供环境地址选择器，也不提供 Supabase 配置。
- 程序只读 WH6 已成交缓存和完整持仓快照，不下单、撤单、改单、平仓、行权，不控制 WH6 进程，也不读取内存或截获网络。
- 采集范围覆盖 WH6 `match.dat`/`position.dat` 中可验证的期货和期权成交与持仓；委托缓存只用于补齐必要字段，不作为成交上传内容。
- 本地配置、设备令牌和 SQLite 存放于 `%LOCALAPPDATA%\WH6成交采集器`；本地数据库升级会先保留一次可验证备份，不自动删除备份。
- 实时成交优先于历史回补；策略不可用时当前交易日仅本地排队，历史扫描暂停。历史日期以服务端正向白名单为准，已生效月结月份不重新上传。
- 页面和服务端只把期权作为第一阶段成交量统计；期货和无法可信识别的跨期组合保留在隔离证据/异常路径，不猜测拆腿。

Mac 本地测试、缓存回放、源文件扫描和构建清单检查不能替代 Windows 11、真实 WH6 或真实 Staging 验收。只有在 Windows x64 上完成首次绑定、离线/重启恢复、账户变化暂停、设备撤销、策略日期边界、双设备去重，并在真实 Staging 页面读回自然产生的新成交后，才可称为 Windows 便携程序验收通过。
